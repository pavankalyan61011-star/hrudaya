## നിങ്ങൾ ആശുപത്രിയിൽ വന്നത് എന്തിന്

നിങ്ങൾക്ക് NSTEMI (ഹൃദയാഘാതത്തിന്റെ ഒരു വിഭാഗം) ആയിരുന്നു. അടിയന്തര ചികിത്സയാണ് വേണ്ടിവന്നത്. 2026-08-31 ന് അഡ്മിറ്റ് ചെയ്യുകയും 2026-09-02 ന് ഡിസ്ചാർജ് ചെയ്യുകയും ചെയ്തു. കേസ് കോഡ്: PCI-2026-001.

## എന്താണ് ചെയ്തത്

വലത് കൈത്തണ്ടയിലെ റേഡിയൽ ധമനിയിലൂടെ (radial artery) ഹൃദയത്തിലെ രക്തക്കുഴലുകളുടെ ആൻജിയോഗ്രാം ചെയ്തു. Proximal LAD (ഹൃദയത്തിന്റെ മുൻഭാഗത്തിലേക്കുള്ള പ്രധാന രക്തക്കുഴലായ ലെഫ്റ്റ് ആന്റീരിയർ ഡിസെൻഡിങ് ആർട്ടറിയുടെ ആദ്യഭാഗം) ലെ ബ്ലോക്കിൽ ഒരു drug-eluting stent (മരുന്ന് പുരട്ടിയ സ്റ്റെന്റ്) ഇട്ടു. ഇതിനുശേഷം ആ ഭാഗത്ത് 0% ചുരുക്കം മാത്രമേയുള്ളൂ, രക്തയോട്ടം TIMI 3 ആണ്.

## ഞങ്ങൾ കണ്ടെത്തിയത്

- LMCA (ലെഫ്റ്റ് മെയിൻ കൊറോണറി ആർട്ടറി): 0% ചുരുക്കം
- Proximal LAD: 90% ചുരുക്കം
- Mid LCX (ലെഫ്റ്റ് സർക്കംഫ്ലെക്സ് ആർട്ടറിയുടെ മധ്യഭാഗം): 40% ചുരുക്കം
- Proximal RCA (റൈറ്റ് കൊറോണറി ആർട്ടറിയുടെ ആദ്യഭാഗം): 30% ചുരുക്കം

## നിങ്ങളുടെ മരുന്നുകൾ

| മരുന്ന് | അളവ് | എത്ര തവണ | എത്ര കാലം |
|---|---|---|---|
| Aspirin (DAPT) | 75 mg | ഒരു ദിവസം ഒരു തവണ (OD) | |
| Ticagrelor (DAPT) | 90 mg | ഒരു ദിവസം രണ്ടു തവണ (BD) | |
| Atorvastatin | 80 mg | ഒരു ദിവസം ഒരു തവണ (OD) | |
| Metoprolol tartrate | 25 mg | ഒരു ദിവസം രണ്ടു തവണ (BD) | |
| Pantoprazole | 40 mg | ഒരു ദിവസം ഒരു തവണ (OD) | |

DAPT എന്നാൽ Aspirin ഉം Ticagrelor ഉം ഒരുമിച്ച് കഴിക്കുന്ന രണ്ടു ഗുളികകളാണ്; ഇവ സ്റ്റെന്റിൽ രക്തം കട്ടപിടിക്കുന്നത് തടയുന്നു. നിങ്ങളുടെ കാർഡിയോളജിസ്റ്റിനോട് ചോദിക്കാതെ ഈ മരുന്നുകൾ നിർത്തരുത്.

## സ്വയം ശ്രദ്ധിക്കാൻ

- DAPT മരുന്നുകൾ മുടങ്ങാതെ കൃത്യമായി കഴിക്കുക.
- പുകവലി പൂർണമായും ഉപേക്ഷിക്കുക.
- കാർഡിയാക് റീഹാബിലിറ്റേഷൻ (ഹൃദയാരോഗ്യ പുനരധിവാസ പരിപാടി) ചെയ്യുക.
- ഹൃദയത്തിന് ഗുണകരമായ ഭക്ഷണക്രമം പാലിക്കുക.
- ശാരീരിക പ്രവർത്തനങ്ങളിലേക്ക് പതുക്കെ പതുക്കെ മടങ്ങുക.
