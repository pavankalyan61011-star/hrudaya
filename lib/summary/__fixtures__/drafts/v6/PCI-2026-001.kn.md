## ನೀವು ಆಸ್ಪತ್ರೆಗೆ ಬಂದ ಕಾರಣ

ನಿಮಗೆ ಹೃದಯಾಘಾತ (NSTEMI) ಆಗಿತ್ತು. ಹೃದಯದ ರಕ್ತನಾಳದಲ್ಲಿ ತೀವ್ರ ಅಡಚಣೆಯಿಂದಾಗಿ ತುರ್ತು ಚಿಕಿತ್ಸೆ ಅಗತ್ಯವಾಯಿತು. ನೀವು 2026-08-31 ರಂದು ದಾಖಲಾಗಿ 2026-09-02 ರಂದು ಬಿಡುಗಡೆಯಾಗಿದ್ದೀರಿ.

## ಏನು ಮಾಡಲಾಯಿತು

ಬಲ ಮಣಿಕಟ್ಟಿನ ರಕ್ತನಾಳದ (radial) ಮೂಲಕ ಹೃದಯದ ರಕ್ತನಾಳಗಳ ಆಂಜಿಯೋಗ್ರಾಮ್ ಮಾಡಲಾಯಿತು. ನಂತರ Proximal LAD (ಹೃದಯದ ಮುಂಭಾಗಕ್ಕೆ ರಕ್ತ ಒದಗಿಸುವ ಪ್ರಮುಖ ನಾಳದ ಆರಂಭದ ಭಾಗ) ದಲ್ಲಿ ಒಂದು ಔಷಧ-ಲೇಪಿತ ಸ್ಟೆಂಟ್ (drug-eluting stent) ಅಳವಡಿಸಲಾಯಿತು. ಸ್ಟೆಂಟ್ ಅಳವಡಿಕೆಯ ನಂತರ ಅಡಚಣೆ 0% ಗೆ ಇಳಿಯಿತು ಮತ್ತು ರಕ್ತದ ಹರಿವು ಸಾಮಾನ್ಯವಾಯಿತು (TIMI 3).

## ನಮಗೆ ಕಂಡುಬಂದ ಅಂಶಗಳು

- LMCA (ಎಡ ಮುಖ್ಯ ಹೃದಯ ರಕ್ತನಾಳ): 0% ಕಿರಿದಾಗುವಿಕೆ, ಅಂದರೆ ಸಾಮಾನ್ಯ.
- Proximal LAD: 90% ಕಿರಿದಾಗುವಿಕೆ (ತೀವ್ರ). ಇದಕ್ಕೆ ಸ್ಟೆಂಟ್ ಹಾಕಲಾಯಿತು.
- Mid LCX (ಹೃದಯದ ಎಡ ಹಿಂಭಾಗಕ್ಕೆ ರಕ್ತ ಒದಗಿಸುವ ನಾಳದ ಮಧ್ಯಭಾಗ): 40% ಕಿರಿದಾಗುವಿಕೆ.
- Proximal RCA (ಹೃದಯದ ಬಲಭಾಗದ ನಾಳದ ಆರಂಭದ ಭಾಗ): 30% ಕಿರಿದಾಗುವಿಕೆ.

## ನಿಮ್ಮ ಔಷಧಿಗಳು

| ಔಷಧ | ಪ್ರಮಾಣ | ಎಷ್ಟು ಬಾರಿ | ಎಷ್ಟು ಕಾಲ |
|---|---|---|---|
| Aspirin (DAPT) | 75 mg | ದಿನಕ್ಕೆ ಒಂದು ಬಾರಿ (OD) | |
| Ticagrelor (DAPT) | 90 mg | ದಿನಕ್ಕೆ ಎರಡು ಬಾರಿ (BD) | |
| Atorvastatin | 80 mg | ದಿನಕ್ಕೆ ಒಂದು ಬಾರಿ (OD) | |
| Metoprolol tartrate | 25 mg | ದಿನಕ್ಕೆ ಎರಡು ಬಾರಿ (BD) | |
| Pantoprazole | 40 mg | ದಿನಕ್ಕೆ ಒಂದು ಬಾರಿ (OD) | |

DAPT ಎಂದರೆ Aspirin ಮತ್ತು Ticagrelor ಎಂಬ ಎರಡು ಮಾತ್ರೆಗಳನ್ನು ಒಟ್ಟಿಗೆ ತೆಗೆದುಕೊಳ್ಳುವುದು; ಇವು ಸ್ಟೆಂಟ್‌ನಲ್ಲಿ ರಕ್ತ ಹೆಪ್ಪುಗಟ್ಟದಂತೆ ತಡೆಯುತ್ತವೆ. ನಿಮ್ಮ ಹೃದ್ರೋಗ ತಜ್ಞರನ್ನು ಕೇಳದೆ ಈ ಔಷಧಿಗಳನ್ನು ನಿಲ್ಲಿಸಬೇಡಿ.

## ನಿಮ್ಮ ಆರೈಕೆ

- DAPT ಔಷಧಿಗಳನ್ನು ತಪ್ಪದೆ, ಕಟ್ಟುನಿಟ್ಟಾಗಿ ತೆಗೆದುಕೊಳ್ಳಿ.
- ಧೂಮಪಾನವನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ನಿಲ್ಲಿಸಿ.
- ಹೃದಯ ಪುನರ್ವಸತಿ (cardiac rehabilitation) ಕಾರ್ಯಕ್ರಮದಲ್ಲಿ ಭಾಗವಹಿಸಿ.
- ಹೃದಯಕ್ಕೆ ಒಳ್ಳೆಯ ಆಹಾರ ಸೇವಿಸಿ.
- ದೈಹಿಕ ಚಟುವಟಿಕೆಗೆ ನಿಧಾನವಾಗಿ, ಹಂತ ಹಂತವಾಗಿ ಮರಳಿ.
