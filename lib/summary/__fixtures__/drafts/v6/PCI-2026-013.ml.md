## നിങ്ങൾ ആശുപത്രിയിൽ വന്നത് എന്തിന്

നിങ്ങൾക്ക് സ്ഥിരമായ നെഞ്ചുവേദന (stable angina) ഉണ്ടായിരുന്നു. ഹൃദയത്തിലെ രക്തക്കുഴലുകൾ പരിശോധിക്കാനും ആവശ്യമെങ്കിൽ ചികിത്സിക്കാനുമായി നേരത്തേ നിശ്ചയിച്ച പ്രകാരമാണ് (Planned) നിങ്ങളെ പ്രവേശിപ്പിച്ചത്. ഉയർന്ന രക്തസമ്മർദ്ദവും ഉയർന്ന കൊളസ്ട്രോളും നിങ്ങൾക്കുണ്ട്. (കേസ് കോഡ്: PCI-2026-013)

## എന്തെല്ലാം ചെയ്തു

വലത്തേ കൈത്തണ്ടയിലെ രക്തക്കുഴലിലൂടെ (radial) ഹൃദയത്തിലെ രക്തക്കുഴലുകളുടെ എക്സ്-റേ പരിശോധന (angiogram) നടത്തി. തുടർന്ന് ഇടത്തേ പ്രധാന രക്തക്കുഴലിന്റെ ശാഖയായ Proximal LAD-യിൽ (Left Anterior Descending, LAD) ഒരു മരുന്നുപുരട്ടിയ സ്റ്റെന്റ് (drug-eluting stent, Everolimus DES) ഘടിപ്പിച്ചു. സ്റ്റെന്റ് തുറക്കാൻ ബലൂണുകളും ഉപയോഗിച്ചു. ചികിത്സയ്ക്കുശേഷം ആ ഭാഗത്ത് ഏകദേശം 5% മാത്രമാണ് ചുരുക്കം ശേഷിച്ചത്, രക്തയോട്ടം സാധാരണ നിലയിലായിരുന്നു (TIMI flow 3).

## ഞങ്ങൾ കണ്ടെത്തിയത്

- LMCA (Left Main Coronary Artery, ഇടത്തേ പ്രധാന രക്തക്കുഴൽ): 0% ചുരുക്കം
- Proximal LAD: 85% ചുരുക്കം, ഇവിടെയാണ് സ്റ്റെന്റ് ഇട്ടത്
- Mid LCX (Left Circumflex): 20% ചുരുക്കം
- RCA (Right Coronary Artery, വലത്തേ രക്തക്കുഴൽ): 0% ചുരുക്കം

എല്ലാ രക്തക്കുഴലുകളിലും രക്തയോട്ടം സാധാരണമായിരുന്നു (TIMI flow 3).

## നിങ്ങളുടെ മരുന്നുകൾ

| മരുന്ന് | അളവ് | എത്ര തവണ | എത്ര കാലം |
|---|---|---|---|
| Aspirin (DAPT) | 75 mg | ദിവസത്തിൽ ഒരിക്കൽ (OD) | |
| Clopidogrel (DAPT) | 75 mg | ദിവസത്തിൽ ഒരിക്കൽ (OD) | 6 മാസം |
| Atorvastatin | 40 mg | ദിവസത്തിൽ ഒരിക്കൽ (OD) | |
| Amlodipine | 5 mg | ദിവസത്തിൽ ഒരിക്കൽ (OD) | |
| GTN | | ആവശ്യമുള്ളപ്പോൾ മാത്രം (PRN) | |

Aspirin, Clopidogrel എന്നിവ ഒരുമിച്ച് കഴിക്കേണ്ട രണ്ട് ഗുളികകളാണ് (DAPT); സ്റ്റെന്റിനുള്ളിൽ രക്തം കട്ടപിടിക്കുന്നത് ഇവ തടയുന്നു. നിങ്ങളുടെ കാർഡിയോളജിസ്റ്റിനോട് ചോദിക്കാതെ ഈ മരുന്നുകൾ നിർത്തരുത്.

## സ്വയം ശ്രദ്ധിക്കേണ്ട കാര്യങ്ങൾ

- DAPT മരുന്നുകൾ മുടങ്ങാതെ, പറഞ്ഞ സമയം വരെ കഴിക്കുക.
